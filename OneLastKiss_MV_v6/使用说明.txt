One Last Kiss — 网页 MV 第六版（宇多田ヒカル）

【播放】
  双击 Play-OneLastKiss-v6.bat：用 Chrome / Edge 以应用窗口打开，允许自动播放（有声音）。
  也可以直接用浏览器打开 index.html；若自动播放被拦截，点一下画面即可开始。
  推荐 Chrome / Edge 最新版，开启硬件加速，全屏（F11）观看。
  第一～五版原样保留在 ../OneLastKiss_MV、../OneLastKiss_MV_v2 … ../OneLastKiss_MV_v5。

【用 OBS 录制 2K 视频】
  录制模式（网址参数 ?rec=1）：画面固定按 2560×1440 渲染、不自动降分辨率、不显示控制条和鼠标、
  CC 字幕默认开启「中文 + 日本語」（画面内三语艺术字幕照常显示），开始后黑场约 1.5 秒再从 0:00 播放。

  方法一（推荐，任何显示器都能录出真 2K）：OBS「浏览器」来源
    1. OBS 设置 → 视频：基础（画布）分辨率 2560x1440，输出（缩放）分辨率 2560x1440，常用 FPS 60。
    2. OBS 设置 → 输出 → 录像：格式 mkv 或 mp4，编码器选显卡硬件编码（NVENC / QSV / AMF），
       码率控制 CQP 18～20（或 CBR 40000 Kbps 以上）。
    3. 来源 → ＋ → 浏览器，取消勾选「本地文件」，URL 填：
         file:///E:/claude%20test/OneLastKiss_MV_v6/index.html?rec=1&auto=1
       宽 2560、高 1440；勾选「通过 OBS 控制音频」；勾选「使用自定义帧率」填 60；
       取消勾选「不可见时关闭源」。
    4. 先点「开始录制」，再在该来源的属性里点「刷新当前页面的缓存」：页面加载完 → 黑场 3 秒 → 从头播放。
       播完（约 4 分 12 秒）停止录制，把片头的加载画面和黑场剪掉即可。
    声音走浏览器来源本身（混音器里会多一个该来源的音轨），不用开桌面音频。

  方法二：窗口 / 显示器采集
    1. 双击 Record-OneLastKiss-v6.bat（全屏打开录制模式）。
    2. OBS 添加「显示器采集」（或「窗口采集」，捕获方式选 Windows 10 (1903+)），音频用「桌面音频」。
    3. 先在 OBS 点「开始录制」，再点画面上的「开始播放（全屏）」按钮或按 Enter。
    注意：这种方式的清晰度取决于显示器，2560x1440 及以上的屏幕才是原生 2K；1080p 屏幕请用方法一。

  如果录出来掉帧：把网址里的 ?rec=1 改成 ?rec=1&q=0.8（画质 80%）。画面始终跟随音乐时钟，
  掉帧不会导致音画不同步。想要英文字幕 CC：加 &cc=zh-en 或 &cc=ja-en。

【操作】
  空格 / K：暂停 / 继续     ← →：快退 / 快进 5 秒     F：全屏     R：从头播放
  L：画面内艺术字幕开 / 关   H：隐藏控制条
  C：视频网站样式字幕（CC）开 / 关（默认开启：中文 + 日本語）     V：切换字幕语言
  网址参数：?rec=1 录制模式（&auto=1 自动开始，&delay=秒 黑场时长）   ?noc 关闭 CC   ?cc=zh / ja / en / zh-ja …
            ?nohud 隐藏 NERV HUD   ?t=秒数 从指定时间开始   ?noem 关闭紧急状态动画   ?nokin 关闭动态设计层

【第六版改动】
  1. 踩点重做：按音频分析出的鼓点 / 重音逐个校准全片镜头切换点，约 20 处切点从"歌词起点"改到真正的重拍上。
     · 两段「Oh oh oh」人物蒙太奇、赤色海面五台 EVA 的依次落位 / 消散，全部对齐副歌里每两拍一次的切分重音。
     · 城市→村庄、晚霞、电车、美里之吻、绫波、渚薰、真嗣蓝海、宇部长椅、铁道、双螺旋等转场改落在重拍上；
       转场附近的镜头运动、闪白与动态设计层同步平移，不会出现镜头提前停住或跳动。
  2. 铁道段（宇部线）完全重做为纯 RGB 线条的抽象 3D：轨道、枕木、接触网、电线杆、道口和电车全部由发光的
     红 / 绿 / 蓝线条勾勒，带色散拖影、扫描线与高动态的网页设计元素（刻度、时刻表、数字跳动、面板擦除）。
  3. 第3新東京市重做质感：大楼加入退台 / 屋顶设备 / 断顶，立面窗格按真实比例排布并随距离抗锯齿，
     楼板层线、雾与天空颜色统一；AT 力场六边形缩小并随镜头距离淡出，航拍镜头拉高拉远看清整座城市。
  4. 新增 OBS 录制模式与 Record-OneLastKiss-v6.bat（见上）。CC 字幕默认开启中文 + 日本語。

【第五版改动】（在第四版基础上中等程度重制）
  1. 新 3D 分镜「第3新東京市」：两段程序化城市大场面。
     · 近第三次冲击：千余栋大楼随红色波前沉入地面，十字光柱踩着节拍从街道爆出，初号机在光环下觉醒。
     · 副歌战斗：燃烧的城市、浓烟与火星，初号机与 13 号机对峙；航拍镜头俯瞰六边形 AT 力场与巨型十字。
  2. 新 3D 分镜「宇部线」：最后副歌改为夏日铁道。
     · 镜头贴着轨道随黄色电车高速前进，接触网架与电线杆按节拍掠过。
     · 道口警灯随节拍交替闪烁，电车呼啸驶过道口，结尾镜头升向太阳，接入双螺旋高潮。
  3. 去掉手书装饰，改为「NERV × 瑞士编辑风」的网页动态设计层：
     · 章节卡：编号、细线、明朝体标题逐字遮罩揭示、时间码、进度条，替换原来的地点字幕。
     · 卢浮宫：精密刻度环与 RESTORATION 计数器由红转蓝。
     · 初号机：齿轮刻度盘踩点转动，飞入后变成眼部锁定准星。
     · 列车段：交通线路图（海 / 車窗 / 父 / 傷）随每个镜头推进。
     · 战斗段：锁定框与距离计数、警告跑马灯。
     · 真嗣海岸：波形线压平成地平线、REWRITE 计数。
     · 转场：彩色面板层叠擦除。
     · 宇部线：翻牌式时刻表与升降高度标尺。
     所有动态元素都避开歌词区域。
  4. 镜头结构调整：原「近第三次冲击」「火焰」「站台」「空中」等插画镜头替换为上述 3D 场景，并重排节奏；
     紧急状态动画的时间点随之调整。

【第四版改动】（在第三版基础上打磨）
  1. 画面亮度自适应：按每张插画的整体亮度自动调整光束 / 泛光 / 对比度，修正绫波白光、真嗣蓝海、
     宇部站台、两人同框等明亮镜头发灰、发白、脸部被光斑糊掉的问题；扫光改为避开高光。
  2. 第二段副歌新镜头：初号机 vs 13 号机 AT 力场正面对撞（新生成插画），六边形冲击波随节拍从撞击点扩散。
  3. 夕阳车厢 3D 场景：窗框、车顶吊挂广告、墙板与地面阴影（伪环境光遮蔽）、云层天空，窗外不再过曝成白块。
  4. 站台驶过的电车：车身明暗、车顶 / 裙边、车门接缝、可透视的车窗与座椅剪影，不再是平面色块。
  5. 结尾"倒带"蒙太奇：缩短卡片的闪白与拖影按时长自动减弱，呈现彩色的录像带倒带质感而不是一片白。
  6. 葛城美里、渚薰等镜头的光束强度微调。

【第三版改动】
  1. 新开场：黑屏 → 漂浮粒子 → 像素点阵 → 镜头拉远，S-DAT 磁带机出现在标志性场景中（一镜到底，不再反复换角度看录音机）。
  2. EVA 式紧急状态全屏动画：在 EVA 出场、人类补完等段落前后，警告条 / 滚动警报 / 六边形格 / 倒计时逐层铺满画面。
  3. 更多程序化 3D：第三次冲击（地球表面十字光柱 → 南极起反 AT 力场六边形壳蔓延 → 灵魂漩涡升向碎裂的黑月，
     背后三维生命之树逐节点点亮，一个长摇臂镜头完成）；朗基努斯 / 加乌斯之枪改为 3D 双螺旋枪身穿越太空、
     绕枪环绕镜头后刺向赤色地球。
     新增闪回镜头：蔚蓝地球漂浮在赤色 LCL 海浪之中（程序化海浪、泡沫、倒影、低角度夕光，胶片颗粒与闪烁）。
