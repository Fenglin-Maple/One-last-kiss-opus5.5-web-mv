One Last Kiss — 网页 MV 第四版（宇多田ヒカル）

【播放】
  双击 Play-OneLastKiss-v4.bat：用 Chrome / Edge 以应用窗口打开，允许自动播放（有声音）。
  也可以直接用浏览器打开 index.html；若自动播放被拦截，点一下画面即可开始。
  推荐 Chrome / Edge 最新版，开启硬件加速，全屏（F11）观看。
  第一～三版原样保留在 ../OneLastKiss_MV、../OneLastKiss_MV_v2、../OneLastKiss_MV_v3。

【操作】
  空格 / K：暂停 / 继续     ← →：快退 / 快进 5 秒     F：全屏     R：从头播放
  L：画面内艺术字幕开 / 关   H：隐藏控制条
  C：视频网站样式字幕（CC）开 / 关     V：切换字幕语言（中文 / 日本語 / English / 双语组合）
  网址参数：?cc 默认开启 CC 字幕   ?nohud 隐藏 NERV HUD   ?t=秒数 从指定时间开始
            ?noem 关闭 EVA 紧急状态全屏动画   ?noteg 关闭手书风格动态装饰层

【第四版改动】（在第三版基础上打磨）
  1. 画面亮度自适应：按每张插画的整体亮度自动调整光束 / 泛光 / 对比度，修正绫波白光、真嗣蓝海、
     宇部站台、两人同框等明亮镜头发灰、发白、脸部被光斑糊掉的问题；扫光改为避开高光。
  2. 第二段副歌新镜头：初号机 vs 13 号机 AT 力场正面对撞（新生成插画），六边形冲击波随节拍从撞击点扩散。
  3. 夕阳车厢 3D 场景：窗框、车顶吊挂广告、墙板与地面阴影（伪环境光遮蔽）、云层天空，窗外不再过曝成白块。
  4. 站台驶过的电车：车身明暗、车顶 / 裙边、车门接缝、可透视的车窗与座椅剪影，不再是平面色块。
  5. 结尾"倒带"蒙太奇：缩短卡片的闪白与拖影按时长自动减弱，呈现彩色的录像带倒带质感而不是一片白。
  6. 葛城美里、渚薰等镜头的光束强度微调。

【第三版改动】
  1. 新开场：黑屏 → 漂浮粒子 → 像素点阵 → 镜头拉远，S-DAT 磁带机出现在标志性场景中（一镜到底，不再反复换角度看录音机）。
  2. EVA 式紧急状态全屏动画：在 EVA 出场、人类补完等段落前后，警告条 / 滚动警报 / 六边形格 / 倒计时逐层铺满画面。
  3. 更多程序化 3D：第三次冲击（地球表面十字光柱 → 南极起反 AT 力场六边形壳蔓延 → 灵魂漩涡升向碎裂的黑月，
     背后三维生命之树逐节点点亮，一个长摇臂镜头完成）；朗基努斯 / 加乌斯之枪改为 3D 双螺旋枪身穿越太空、
     绕枪环绕镜头后刺向赤色地球。
     新增闪回镜头：蔚蓝地球漂浮在赤色 LCL 海浪之中（程序化海浪、泡沫、倒影、低角度夕光，胶片颗粒与闪烁）。
  4. 镜头节奏重排：快慢分明，该慢的段落放慢；合并零碎镜头；新增 AT 力场六边形翻转转场等过渡。
  5. 地球建模材质分辨率提升（地表 / 云 / 海冰细节）。
  6. 手书（动画手书）风格跨分镜动态层：红线在画面间穿行成圈、齿轮飞入成瞳孔、路线图、锁定框、纸片转场、
     手写注记与光点等，以 8fps "抖线" 质感叠加在插画分镜上。
