One Last Kiss — 网页 MV 第二版（宇多田ヒカル）

【播放】
  双击 Play-OneLastKiss-v2.bat：用 Chrome / Edge 以应用窗口打开，允许自动播放（有声音）。
  也可以直接用浏览器打开 index.html；若自动播放被拦截，点一下画面即可开始。
  推荐 Chrome / Edge 最新版，开启硬件加速，全屏（F11）观看。第一版保留在 ../OneLastKiss_MV。

【操作】
  空格 / K：暂停 / 继续     ← →：快退 / 快进 5 秒     F：全屏     R：从头播放
  L：画面内艺术字幕开 / 关   H：隐藏控制条
  C：视频网站样式字幕（CC）开 / 关     V：切换字幕语言
     （中文 / 日本語 / English / 中文+日本語 / 日本語+English，也可点控制条上的 CC 按钮选择）
  网址参数：index.html?cc 默认开启 CC 字幕；index.html?nohud 隐藏 NERV 风格 HUD；?t=秒数 从指定时间开始。

【第二版内容】
  全长约 4 分 12 秒，所有画面由 WebGL 实时渲染，并与音乐的鼓点 / 军鼓 / 段落起伏逐拍同步。
  S-DAT 磁带机开场（26→27）→ 最终話 标题卡 → 巴黎红 / 蓝世界改写 → 画廊 → 初号机笼 → 第三村与水田
  → 晾衣绳 → 天空与飞船舰队 → 回忆快切 → 峡谷 / 莉莉丝 → 摄影棚（虚构与现实的边界）→ 列车 → 火海战斗
  → 美里 / 朗基努斯之枪 → 人类补完：地球化为赤潮、众 EVA 在红海安息 → 真嗣与母亲 → 补完终了、地球复青
  → 负宇宙：原画纸飞舞成龙卷、隧道、墙 → 宇部新川站 → 记忆螺旋（亲友面孔、彩虹反向螺旋）
  → 蓝色地球 → 全片倒带 → 铅笔尾声（海边小镇，两人牵手奔跑，手写片名）。
