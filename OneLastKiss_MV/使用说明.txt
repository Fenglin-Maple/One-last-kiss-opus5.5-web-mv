One Last Kiss — 网页 MV（宇多田ヒカル）

【播放】
  双击 Play-OneLastKiss.bat：用 Chrome / Edge 以应用窗口打开，并允许自动播放（有声音）。
  也可以直接用浏览器打开 index.html；如果浏览器拦截自动播放，点一下画面就会开始。
  推荐使用 Chrome / Edge 最新版，开启硬件加速，全屏观看（F11）。

【操作】
  空格：暂停 / 继续    ← →：快退 / 快进 5 秒    F：全屏    R：从头播放
  L：字幕开 / 关        H：隐藏控制条
  移动鼠标会显示进度条，可以点击跳转。

【内容】
  全长约 4 分 12 秒，所有画面都由 WebGL 实时渲染并与音乐同步：
  手写标题序章 → 卢浮宫 → 肖像 → 齿轮 → 拍立得 → 星河 → 取景器 → 放映机 → 夜站台 → 余烬 → 燃烧的星河
  → 隧道 → 赤色之海 → 光之螺旋 → 胶片灯箱 → 铅笔尾声。
  字幕为日语 / 中文 / 英文三语，排版随每一幕的风格变化。
  插画素材为原创 AI 生成的二次元风格画稿，并全部做成了动态效果（深度视差、风、水波、光效、手绘显现等）。

【文件】
  index.html / assets/   成品（离线可用，无需服务器、无需联网）
  source/                源码（three.js + esbuild），重新打包：在 source 下执行 npm install 后 node build.mjs
