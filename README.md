# One Last Kiss 网页 MV

这是使用 Claude Opus 5.5 制作的网页 MV，歌曲为宇多田ヒカル《One Last Kiss》（《新·福音战士剧场版：终》主题曲）。项目包含六个迭代版本，每个版本都可以直接在浏览器中运行。

## 使用方法

进入对应版本的文件夹：

- 直接用浏览器打开 `index.html`。
- Windows 用户也可以双击对应的 `.bat` 启动脚本。
- v6 另提供 `Record-OneLastKiss-v6.bat`，用于 OBS 录制模式启动。

## 版本说明

- **v1**：基础引擎，程序化场景与三语 CC 字幕。
- **v2**：新增复杂 3D 场景、更多 AI 生图素材，以及更紧的踩点。
- **v3**：EVA 风格全屏 EMERGENCY UI、S-DAT 开场重做，以及 Third Impact 大场面。
- **v4**：画面过曝修复、自适应亮度引擎，以及 AT 力场冲突场景。
- **v5**：东京 3 号城市战场景、铁路场景，手书层替换为网页动效排版。
- **v6**：Rails 场景改为纯 RGB 线框风格，全片踩点重校，提供 2K 录制模式（OBS），并默认开启中日字幕；另含 B 站投稿素材。

## 目录结构

每个版本包含播放器入口 `index.html`、Windows 启动脚本、运行时资源 `assets/`、源代码 `source/` 和中文使用说明。v6 额外包含 `bilibili/` 投稿素材文件夹。
