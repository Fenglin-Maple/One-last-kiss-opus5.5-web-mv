# One Last Kiss 网页 MV

这是使用 Claude Opus 5.5 制作的网页 MV，歌曲为宇多田ヒカル《One Last Kiss》（《新·福音战士剧场版：终》主题曲）。项目包含六个迭代版本，每个版本都可以直接在浏览器中运行。

## 使用方法

进入对应版本的文件夹：

- 直接用浏览器打开 `index.html`。
- Windows 用户也可以双击对应的 `.bat` 启动脚本。
- v6 另提供 `Record-OneLastKiss-v6.bat`，用于 OBS 录制模式启动。

## 版本说明

- **v1**：基础引擎，程序化场景与三语 CC 字幕。
- **v2**：新增复杂 3D 场景、更多 AI 生图素材，以及更紧的踩点。
- **v3**：EVA 风格全屏 EMERGENCY UI、S-DAT 开场重做，以及 Third Impact 大场面。
- **v4**：画面过曝修复、自适应亮度引擎，以及 AT 力场冲突场景。
- **v5**：东京 3 号城市战场景、铁路场景，手书层替换为网页动效排版。
- **v6**：Rails 场景改为纯 RGB 线框风格，全片踩点重校，提供 2K 录制模式（OBS），并默认开启中日字幕；另含 B 站投稿素材。

## 目录结构

每个版本包含播放器入口 `index.html`、Windows 启动脚本、运行时资源 `assets/`、源代码 `source/` 和中文使用说明。v6 额外包含 `bilibili/` 投稿素材文件夹。

## Claude Opus 5.5 创作提示词

以下是六个版本制作时使用的主要提示词，保留版本迭代过程与创作要求。

### v1（2026-09-29）

> 在文件夹中，基于音乐和歌词，发挥你最佳艺术创造者的设计能力，制作包含丰富视觉动态效果、部分剧情体现的网页 MV 动画，要可以自动播放。
>
> 过程大纲和详细设计完全由你自行设计，最终输出一个极佳的成品在文件夹给我，你可以使用任意技术栈、任意部署需要的工具（在文件夹内）。
>
> 旧的文件不用管。

### v2（2026-09-29）

> 还不错，接下来做第二版（保留第一版，但是可以参考一部分）。
>
> 第二版要求：
>
> 1. 增加 3D 复杂场景表现，具体场景内根据（抽象化或者不抽象的）歌词增加什么内容，你自己设计。
> 2. 增加图片丰富程度，减少复用，可以继续生成需要的图片。
> 3. 增强音乐踩点，你可以先识别一下音乐的节奏旋律起伏。
> 4. 增加分镜细分粒度和场景变化，不一定每段都把分镜拆得更细，但是也不能全是那种大段单调连续的分镜。
> 5. 基于以上要求，再补充你自己的额外设计，第二版不必完全照搬第一版概念设计，你可以继续设计。
> 6. 生成完之后你可以自己审阅一下细节问题。
> 7. 增加可以打开和关闭的一般视频网站样式字幕，支持中文、日语、英语切换。
> 8. 缺失的图片、音乐、背景知识等素材也可以自己去网上找。
> 9. 可以生成原主角、配角、EVA、飞船等相关的图像。

> 注：原提示词第 7 条中的“源于”是“英语”的笔误，实际要求为中文、日语、英语三种字幕切换。

### v3（2026-09-29）

> 保留第二版文件，基于第二版制作第三版（新建文件夹），做出优化。
>
> 1. EVA 出现的部分合适的分镜镜头（同时分镜前后），可以增加部分 EVA 特有的那种平面设计的紧急状态全屏动画，就是那种逐渐覆盖满的各种紧急状态滚动条，具体样式你可以去网上搜索，然后自己实现设计植入 MV 内。
> 2. 开头多个镜头旋转看一个录音机有点意义不明，一直换镜头看一个简单的东西观感较差，优化这段表现。
> 3. 许多地方依赖生成的图片，导致你自己制作的 3D 复杂效果比较少，增加一些设计。
> 4. 优化整体镜头节奏，虽然细，但是有点乱，增加或优化动态镜头设计。同时可以增加一些分镜过渡效果。
> 5. 优化后面出现的地球建模的材质分辨率。
> 6. 缺少震撼的分镜或者画面。人类全球补完那边的动画有点太简略。
>
> 以上要求不一定逐字遵循，如果你有好的设计和想法，或者美学优化整体设计，可以自行按你的想法优化想要优化的部分。你拥有较高的自主决策权。

### v4（2026-09-30）

>
> 设计、实现完全由你把控。
